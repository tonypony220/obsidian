# Linux Virtual Network Devices

moc: [[networking-moc]]
next: [[veth-pair]] [[linux-bridge]] [[tun-tap]] [[vxlan]] [[linux-network-interface]] [[docker-networking]]

---

```
Физический мир          Linux-аналог
─────────────           ────────────
Ethernet-кабель    ──▶  veth pair
Свитч              ──▶  bridge
Сетевая карта      ──▶  tun/tap
Туннель (L2/L3)    ──▶  vxlan
```

Linux задумывался как серверная ОС. На одном физическом сервере — десятки сервисов, контейнеров, VM, и все хотят сеть. Покупать физическую сетевую карту каждому контейнеру — абсурд. Поэтому ядро Linux умеет создавать виртуальные сетевые устройства, повторяющие логику реального железа.

## Четыре базовых примитива

- [[veth-pair]] — виртуальный кабель. Пара интерфейсов, соединённых напрямую (L2)
- [[linux-bridge]] — виртуальный свитч. Объединяет несколько интерфейсов в одну L2-сеть
- [[tun-tap]] — виртуальная сетевая карта. Позволяет userspace-программе читать/писать пакеты
- [[vxlan]] — виртуальный туннель. Инкапсулирует L2-кадры в UDP для передачи через L3-сеть

## Зачем это всё

Docker, Kubernetes, облака (AWS, GCP) — всё построено на этих примитивах. Когда делаешь `docker run`, Docker внутри создаёт [[veth-pair]] и подключает его к [[linux-bridge]] `docker0`.
