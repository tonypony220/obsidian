```
 индексация:  документы → чанки → эмбеддинги → векторный индекс
 запрос:      "как вернуть деньги" → эмбеддинг → top-k ближайших
                                                   │
              находит "порядок возврата средств" (слов не совпало)
```

**TL;DR:** документы и запрос превращаются в [[embeddings]], а результатом становятся ближайшие по смыслу куски, даже без общих слов.

- Пайплайн: нарезка на чанки → эмбеддинг каждого → индекс → эмбеддинг запроса → top-k по близости.
- Чанки: слишком большие размывают смысл, слишком маленькие теряют контекст. Размер подбирается по данным.
- Точный перебор всех векторов дорог; приближённый поиск: [[hnsw-index]], [[ivf-index]]. Цена скорости — [[recall]] индекса (часть настоящих соседей не находится).
- Слабое место: точные термины, коды, имена. Часто комбинируют с лексическим поиском (BM25) — гибридный поиск.
- Качество проверяют так же, как классификатор: набор запросов с известными правильными документами, метрики recall@k, [[precision]].
- Ядро RAG: найденные куски подставляются в запрос к LLM, см. [[prompting-vs-rag-vs-finetuning]].
