```
  фото фрукта ──▶ модель ──▶ баллы:   яблоко 2.0 │ груша 1.0 │ банан −1.0
                                         │
                                      softmax
                                         ▼
                             проценты:  яблоко 70% │ груша 26% │ банан 4%   (сумма 100%)
```

**TL;DR:** Softmax превращает набор любых баллов (логитов) в проценты, которые в сумме дают 100%. Чем больше балл, тем больше процент. Это [[sigmoid]] для случая, когда вариантов больше двух.

## Задача

Модель для каждого варианта выдаёт балл — просто число, может быть отрицательным. Нужно превратить баллы в «насколько модель уверена в каждом варианте» так, чтобы:
1. каждый процент был от 0 до 100
2. все вместе давали 100
3. больший балл → больший процент

## Почему не просто поделить на сумму

Баллы $2.0, 1.0, -1.0$, сумма $2.0$:
- яблоко $2 / 2 = 100\%$, груша $50\%$, банан $-50\%$

Отрицательный процент — бессмыслица. Нужно сначала сделать все баллы положительными.

## Решение: экспонента, потом деление на сумму

Шаг 1. Возвести $e \approx 2.718$ в степень каждого балла. Результат всегда положительный, и больший балл даёт большее число:

| | балл | $e^{\text{балл}}$ |
|---|---|---|
| яблоко | 2.0 | 7.39 |
| груша | 1.0 | 2.72 |
| банан | −1.0 | 0.37 |
| | | сумма 10.48 |

Шаг 2. Поделить каждое на сумму:
- яблоко $7.39 / 10.48 = 70\%$
- груша $2.72 / 10.48 = 26\%$
- банан $0.37 / 10.48 = 4\%$

Все условия выполнены. Это и есть softmax.

## Формула

То же самое для варианта $k$ с баллом $z_k$:

$$
p_k = \frac{e^{z_k}}{\sum_j e^{z_j}}
$$

## Важны только разницы баллов

Прибавим 10 ко всем баллам: $12, 11, 9$. Проценты не изменятся — те же 70/26/4. Экспонента превращает сложение в умножение: $e^{z+10} = e^z \cdot e^{10}$, и общий множитель $e^{10}$ сокращается при делении на сумму.

Значит, смысл имеет только, **на сколько** один балл больше другого. Разница в 1 балл = примерно в 2.7 раза больше процент.

## Связь с сигмоидой

Два варианта: «да» с баллом $z$ и «нет» с баллом $0$ (раз важны только разницы, один балл можно зафиксировать нулём). Softmax для «да»:

$$
\frac{e^{z}}{e^{z} + e^{0}} = \frac{e^z}{e^z + 1} = \frac{1}{1 + e^{-z}}
$$

Это ровно [[sigmoid]]. То есть логрег на 2 класса — частный случай softmax. Логрег на много классов (softmax-регрессия): для каждого класса свой балл $z_k = w_k \cdot x + b_k$, потом softmax.

Альтернатива — [[one-vs-all]]; сравнение → [[logistic-regression#Больше двух классов]].

## Как обучается

Та же [[log-loss]]: штраф $= -\ln(p_{\text{правильный}})$. Если на фото яблоко и модель дала ему 70%, штраф $-\ln 0.70 = 0.36$. Дала бы 4% — штраф $3.2$. Обучение двигает веса так, чтобы процент правильного варианта рос.

## Где встречается

- последний слой многоклассового классификатора
- последний слой LLM: варианты = все токены словаря ([[logreg-to-llm]])
- с делителем $T$ перед экспонентой — [[temperature]]
- внутри трансформеров: attention решает, на какие слова смотреть, тоже через softmax
