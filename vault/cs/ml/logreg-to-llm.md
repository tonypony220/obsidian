```
  логрег:  признаки x (задаёте вы) ──▶ z = w·x + b ──▶ sigmoid ──▶ p
  LLM:     текст ──▶ трансформер ──▶ x (4096 чисел) ──▶ z_k = w_k·x + b_k ──▶ softmax ──▶ p(токен)
                     └──── "извлекатель признаков" ────┘   └──── та же логрег ────┘
```

**TL;DR:** Это то же самое. Последний слой LLM буквально является многоклассовой логистической регрессией.

## Логистическая регрессия (2 класса)

- Считаем линейную комбинацию признаков: $z = w \cdot x + b$. Это и есть логит.
- Логит = log-odds = $\ln\frac{p}{1-p}$. Отсюда название: логит — это логарифм шансов.
- Сигмоида превращает его в вероятность: $p = \frac{1}{1 + e^{-z}}$.

## Многоклассовая (softmax-регрессия)

- Для каждого класса $k$ свой логит: $z_k = w_k \cdot x + b_k$.
- Softmax превращает логиты в вероятности, которые в сумме дают 1.
- Сигмоида — это частный случай softmax для двух классов. Если взять softmax от $(z, 0)$, получится ровно $\frac{1}{1+e^{-z}}$.

## LLM

- Трансформер прогоняет текст через много слоёв и на выходе даёт вектор признаков $x$ для текущей позиции (например, 4096 чисел).
- Последний слой: $z_k = w_k \cdot x + b_k$ для каждого токена словаря (~100–200 тысяч «классов»).
- Softmax даёт вероятности следующего токена.
- Обучается он так же, через cross-entropy (log loss), как и логрег.

То есть LLM — это огромный «извлекатель признаков» плюс обычная softmax-регрессия сверху. Вся сложность сидит в том, как получаются признаки $x$. Сама финальная классификация — та же логистическая регрессия.

## Отличия только в использовании

| | логрег | LLM |
|---|---|---|
| классы | обычно несколько | весь словарь |
| признаки | задаёте вы | модель учит их сама |
| что делают с вероятностями | обычно берут argmax или порог | сэмплируют, часто с температурой |
| температура | обычно не используют | ручка «креативности» |

Деление на $T$ тоже существует в классическом ML: это temperature scaling, способ калибровки вероятностей классификатора. Подбирают одно число $T$ на валидации, чтобы «уверенность 80%» действительно означала 80% правильных ответов ([[temperature]]).
