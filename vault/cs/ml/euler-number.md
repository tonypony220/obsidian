# Число e — откуда берётся 2.718

moc: [[ml-moc]]
next:
- [[logarithm]]
- [[sigmoid]]

---

$$e \approx 2.71828$$

**TL;DR:** $e$ — постоянное число, как $\pi$. Оно возникает, если рост на 100% за период разбить на всё более мелкие начисления, каждый раз считая прирост от текущей суммы.

Начинаем с 1. Делим ставку 100% на равные части:

| Начисления за период | Итог |
|---|---|
| Один раз +100% | $1\cdot2=2$ |
| Два раза по +50% | $1\cdot1.5\cdot1.5=2.25$ |
| Четыре раза по +25% | $1.25^4\approx2.4414$ |
| $n$ раз по $100/n$ процентов | $(1+1/n)^n$ |

В скобках: **сохранить текущее + добавить его долю**. Степень $n$: повторить начисление $n$ раз. Итог больше 2, потому что уже начисленный прирост тоже растёт.

$$e=\lim_{n\to\infty}\left(1+\frac1n\right)^n$$

**Предел** здесь означает: чем больше $n$, тем ближе результат к фиксированному числу $e$. При $n=100$ получается примерно $2.7048$, при $n=1000$ — $2.7169$. Это смысл записи; доказательство можно оставить на потом.

Для чтения ML-формул пока достаточно: $e$ — число, $e^x$ — степень, а $\ln$ — [[logarithm|логарифм]] по основанию $e$.
