```
            ┌─ модель G: «Gryffindor?» ─► 0.02 ┐
студент x ──┼─ модель H: «Hufflepuff?» ─► 0.44 ┼──► argmax ──► Hufflepuff
            ├─ модель R: «Ravenclaw?»  ─► 0.00 ┤
            └─ модель S: «Slytherin?»  ─► 0.00 ┘
```

**TL;DR:** логистическая регрессия умеет только «да/нет» → обучаем 4 независимые бинарные модели «этот факультет vs все остальные», на predict берём ту, что дала наибольшую $h$.

## Обучение: 4 раза один и тот же цикл

![[one-vs-all-relabel.png]]

- Для модели $k$ перекодируем ответ: $y = 1$ если студент из факультета $k$, иначе $y = 0$
- Дальше — обычный цикл из [[logistic-regression-training]], без изменений
- Итог: 4 набора $(w, b)$, каждый со своей границей $h = 0.5$ ([[decision-boundary]])

| Студент | Факультет | $y$ для G | $y$ для H | $y$ для R | $y$ для S |
|---|---|---|---|---|---|
| 1 | Gryffindor | 1 | 0 | 0 | 0 |
| 2 | Ravenclaw | 0 | 0 | 1 | 0 |

## Predict: [[argmax]]

![[one-vs-all-argmax.png]]

$$\text{факультет} = \arg\max_k \; h_k(x), \qquad h_k(x) = \sigma(w_k \cdot x + b_k)$$

- **Слева:** 4 границы по отдельности не делят плоскость чисто: между облаками точки, где «да» говорят двое, или никто
- **Справа:** argmax решает это: каждая точка → факультет с максимальной $h$. Порог 0.5 не нужен
- Звезда: все 4 модели ниже 0.5, но H больше всех (0.44) → Hufflepuff
- $\sum_k h_k \ne 1$: модели обучены независимо и друг о друге не знают. Это 4 оценки уверенности, не распределение. Для argmax не важно. Сравнение с [[softmax]] → [[logistic-regression#Больше двух классов]]

## Почему не одна модель с $y \in \{0,1,2,3\}$

$\sigma$ выдаёт число в $(0, 1)$ → «вероятность класса 1». Номера факультетов — не величины: Ravenclaw (2) не «между» Hufflepuff (1) и Slytherin (3), а $h = 0.5$ не значит ничего.

## В dslr

- `logreg_train`: 4 прогона цикла → файл весов: 4 строки $(b, w_1 \dots w_n)$ + mean/std признаков для нормализации
- `logreg_predict`: загрузить веса → для каждого студента 4 значения $h$ → argmax → `houses.csv` (`Index,Hogwarts House`)
- Картинки выше — синтетика с 2 признаками; задание такой график не требует (обязательные: histogram, scatter, pair plot). В dslr признаков ~13 → границы — плоскости в 13-мерном пространстве, нарисовать нельзя

## Не только в логистической регрессии

- **SVM:** бинарный по природе → мультикласс через тот же one-vs-rest
- **Детекция объектов:** отдельный бинарный детектор на каждый класс + выбор максимального скора
- **Мульти-лейбл (теги):** те же N бинарных моделей, но без argmax — берут все с $h > $ порога

Общее везде: задача на N классов сводится к N вопросам «да/нет», ответы склеиваются правилом выбора.
