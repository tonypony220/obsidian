# Логистическая регрессия

moc: [[ml-moc]]
next: [[svm]] [[random-forest]] [[centroid]] [[confusion-matrix]] [[score-distribution]]

---

```
  1.0 │                          ╭─────────
      │                      ╭──╯
  0.5 │──────────────────╭───╯
      │              ╭───╯
  0.0 │──────────────╯
      └──────────────────────────────────
      -∞    низкий score      высокий score
               класс B           класс A
```

Модель сама находит оптимальную разделяющую плоскость между классами. Подбирает вес для каждого измерения:

```
score = w1·x1 + w2·x2 + ... + w768·x768 + bias
```

На выходе — число от 0 до 1 (вероятность класса A). Чем ближе к 1 — тем увереннее модель что это класс A, чем ближе к 0 — класс B.

В отличие от центроида, видит какие координаты важны для разделения, а какие — шум. Хорошо работает когда данных меньше чем измерений (755 примеров, 768 фич).

## Три и более классов

Для двух классов — одно число (вероятность класса A, вероятность B = 1 − A).

Для трёх классов модель выдаёт три числа, в сумме дающие 1.0:

```
жильё: 0.85, работа: 0.05, мусор: 0.10 → жильё
```

Под капотом — три отдельных логрегрессии (по одной на класс), нормализованные через **softmax** (превращает любые числа в вероятности с суммой 1.0). Побеждает класс с наибольшей вероятностью.
