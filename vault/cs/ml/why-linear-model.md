**TL;DR:** линейность не следует из математики — это **наш выбор семейства функций** (просто, интерпретируемо, часто хватает). Модель подбирает только числа $w, b$ внутри этой формы, а сигмоида уже выводится алгеброй.

## Три разных вещи

| Что | Кто решает | Пример |
|---|---|---|
| Структура модели | мы, до обучения | $f(x) = w x + b$ |
| Параметры | модель, по данным | $w = 2,\ b = -4$ |
| Следствие | математика | из log-odds $= w x + b$ → $p = \sigma(w x + b)$ |

## Линейную функцию просто выбрали

Задача: $x$ — число подозрительных слов в объявлении, $y \in \{0, 1\}$ — мошенническое или нет. Можно взять любое семейство:

- $f(x) = w x + b$
- $f(x) = a x^2 + b x + c$
- $f(x) = \text{NeuralNetwork}(x)$

Ничто не заставляет брать линейную. Берут, потому что:
- **просто**: мало параметров, мало данных нужно, выпуклая задача обучения
- **интерпретируемо**: знак и величина $w_i$ = вклад признака
- **часто достаточно**: нелинейность можно добавить признаками ($x^2$, $x_1 x_2$), форма модели останется линейной по $w$

## Что значит «мы предполагаем»

Предположение = решили описывать закономерность определённой формулой и **потом проверяем** на данных, насколько подходит. Не утверждение, что мир так устроен.

Пример: $\text{Price} = w \cdot \text{Area} + b$. Реальная цена зависит от района, ремонта, этажа — но в модели форма зафиксирована.

## Линейна не вероятность, а log-odds

Ключевое предположение логистической регрессии:

$$\ln\frac{p}{1-p} = w x + b$$

- Линейна левая часть (логарифм шансов), **не** сама $p$
- Сигмоида отдельно не выбирается: выражаем $p$ из этого равенства → $p = \frac{1}{1 + e^{-(w x + b)}}$ (пошагово: [[sigmoid]])

## Концепция шире

- **Регрессия / МНК**: выбрали форму $y = w x + b$ и гауссов шум → МНК выводится ([[least-squares-from-likelihood]])
- **Физика**: закон Гука $F = -k x$ — выбранная модель, $k$ измеряют, работает в пределах упругости
- **Статистика (GLM)**: выбор link-функции (logit, probit, log) + линейный предиктор; остальное — следствие
- **Нейросети**: архитектуру выбирает человек, веса — градиентный спуск

Общее везде: **форму фиксирует человек, числа — данные, следствия — математика**; модель хороша ровно настолько, насколько форма подходит данным.
