**TL;DR:** штраф за одного студента $= -\ln(\text{вероятность, которую модель дала правильному ответу})$. Уверенно угадал → ≈ 0, уверенно ошибся → ∞. Ошибка модели $J$ = среднее штрафов по всем студентам; её и минимизирует градиентный спуск — роль [[mse]] в классификации.

## Почему «бинарная»

В этой заметке модель отвечает на вопрос «Гриффиндор — да или нет?». **Бинарная = два возможных ответа.** Если модель дала «да» 80%, то на «нет» остаётся 20%: вместе они должны дать 100%.

- Студент действительно из Гриффиндора → берём 80% и считаем штраф $-\ln 0.8$.
- Студент из другого факультета → берём 20% и считаем штраф $-\ln 0.2$.

Если выбирать сразу один из четырёх факультетов, ответов будет четыре. Правило штрафа останется тем же: берём вероятность, которую модель дала **настоящему факультету**. Поэтому log-loss бывает и для двух ответов, и для многих.

## Откуда log loss, entropy и cross

**Log loss** буквально означает «логарифмический штраф»: **log** — логарифм, **loss** — ошибка, которую уменьшают при обучении. В нашей формуле логарифм записан как $\ln$.

Чтобы понять слово **энтропия**, начнём с неожиданности. Модель обещала Гриффиндор с вероятностью 99%, а оказался Слизерин — большая неожиданность. Случился Гриффиндор — маленькая. Число $-\ln(\text{вероятность случившегося})$ измеряет эту неожиданность.

Теперь представим мешок с записками «да» и «нет». Достаём записку, возвращаем её и перемешиваем:

- Все записки «да» → ответ известен заранее, неопределённости нет.
- Половина «да», половина «нет» → предсказать ответ труднее всего.

**Энтропия** измеряет эту неопределённость: сколько неожиданности в среднем дают вытягивания, если мы знаем настоящие доли записок в мешке и считаем по ним.

**Cross-entropy — кросс-энтропия:** записки вытягиваем из настоящего мешка, но неожиданность считаем по **предположениям модели**. Например, в мешке поровну «да» и «нет», а модель каждый раз обещает «да» с вероятностью 99%. Каждое «нет» получает огромный штраф, хотя случается примерно в половине случаев.

Отсюда **cross** («перекрёстная»): соединяем **то, что происходит на самом деле**, и **вероятности, которые этому назначила модель**. В обучении вместо записок — реальные ответы из данных. Средний log-loss по этим ответам оценивает кросс-энтропию; чем точнее модель выучила вероятности, тем меньше ожидаемый штраф.

## Как выдаётся штраф: по шагам

Для каждого студента $i$:

1. **Модель говорит:** $h_i = \sigma(w \cdot x_i + b)$ — вероятность «да» ([[sigmoid]])
2. **Берём вероятность правильного ответа:**
   - $y_i = 1$ (правда «да») → модель дала ему $h_i$
   - $y_i = 0$ (правда «нет») → модель дала ему $1 - h_i$
3. **Штраф** $= -\ln(\text{эта вероятность})$
4. **Ошибка модели** $J$ = среднее штрафов по всем $N$ студентам

## Пример: модель «Гриффиндор?», 4 студента

| Студент | Правда $y$ | Модель $h$ | Правильному ответу дали | Штраф              |
| ------- | ---------- | ---------- | ----------------------- | ------------------ |
| A       | 1          | 0.9        | $0.9$                   | $-\ln 0.9 = 0.11$  |
| B       | 1          | 0.2        | $0.2$                   | $-\ln 0.2 = 1.61$  |
| C       | 0          | 0.1        | $1 - 0.1 = 0.9$         | $-\ln 0.9 = 0.11$  |
| D       | 0          | 0.95       | $1 - 0.95 = 0.05$       | $-\ln 0.05 = 3.00$ |

$$J = \frac{0.11 + 1.61 + 0.11 + 3.00}{4} \approx 1.21$$

D — уверенная ошибка (95 % «да», а правда «нет») → больше всех тянет $J$ вверх → градиент сильнее всего двигает веса из-за него.

## Одной формулой

Шаг 2 («какую ветку брать») записывают без `if`, через $y$ как переключатель:

$$\text{штраф}_i = -\big[\, y_i \ln h_i + (1 - y_i) \ln(1 - h_i) \,\big]$$

- $y_i = 1$: вторая часть $\times 0$ исчезает → $-\ln h_i$
- $y_i = 0$: первая часть $\times 0$ исчезает → $-\ln(1 - h_i)$

$$J(w, b) = -\frac{1}{N} \sum_{i=1}^{N} \big[\, y_i \ln h_i + (1 - y_i) \ln(1 - h_i) \,\big]$$

## Почему $-\ln$

- $\ln$ от вероятности $\in (0, 1]$ отрицателен → минус делает штраф положительным
- $\ln 1 = 0$: идеальный ответ — ноль штрафа
- $\ln p \to -\infty$ при $p \to 0$: уверенная ошибка штрафуется без предела
- Глубже: среднее $-\ln$ = минус логарифм правдоподобия (вероятность увидеть все ответы $= \prod p_i$, логарифм → сумма) — тот же рецепт, что дал МНК → [[least-squares-from-likelihood]]

## Почему не MSE

MSE + сигмоида → градиент гаснет при уверенной ошибке. Разбор с картинкой → [[logistic-regression-gradient]].

## В коде

```python
h = sigmoid(X @ w + b)
eps = 1e-15                       # ln(0) = -inf → обрезаем
h = np.clip(h, eps, 1 - eps)
J = -np.mean(y * np.log(h) + (1 - y) * np.log(1 - h))
```

## Не только в бинарной классификации: LLM

В [[logreg-to-llm|LLM]] вариантов ответа много: каждый токен словаря — возможное продолжение текста. Токен — кусочек текста, иногда целое слово. Модель раздаёт вариантам вероятности, которые вместе дают 100%.

Например, в обучающем тексте написано «Столица Франции — Париж». После «Столица Франции —» проверяем, сколько модель поставила на «Париж» (предположим, это один токен):

- Дала 80% → штраф $-\ln 0.8\approx0.22$.
- Дала 1% → штраф $-\ln 0.01\approx4.61$.

При обучении предсказанию следующего токена такие штрафы усредняют по позициям текста. Это называют **категориальной кросс-энтропией**: выбираем один ответ из многих. Принцип тот же, что с Гриффиндором: повышаем вероятность правильного ответа; вместо «да/нет» — весь словарь.
