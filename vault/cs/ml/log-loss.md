**TL;DR:** штраф за одного студента $= -\ln(\text{вероятность, которую модель дала правильному ответу})$. Уверенно угадал → ≈ 0, уверенно ошибся → ∞. Ошибка модели $J$ = среднее штрафов по всем студентам; её и минимизирует градиентный спуск — роль [[mse]] в классификации.

## Откуда названия и почему здесь «бинарная»

**Log loss** = логарифмический штраф: берём $-\ln$ от вероятности правильного ответа. **Cross-entropy** = кросс-энтропия: название той же функции со стороны теории информации.

- **Неожиданность события:** $-\ln p$. Чем меньше вероятность случившегося, тем больше неожиданность.
- **Энтропия:** средняя неожиданность событий из распределения $P$, если оценивать их вероятности по самому $P$: $H(P)=-\sum_k P_k\ln P_k$.
- **Кросс-энтропия:** события по-прежнему приходят из $P$, но оцениваем их по вероятностям модели $Q$: $H(P,Q)=-\sum_k P_k\ln Q_k$. Отсюда **cross**: в расчёте участвуют два распределения — целевое и предсказанное.

Для одного примера с известным классом целевое распределение — $1$ у правильного класса и $0$ у остальных. В сумме остаётся только $-\ln Q_{\text{правильный класс}}$.

Здесь задача «Гриффиндор — да или нет?»: **два класса**, поэтому кросс-энтропия **бинарная**. Целевые вероятности $(y,1-y)$, предсказанные — $(h,1-h)$. Подставляем их в общую сумму:

$$H(P,Q)=-[y\ln h+(1-y)\ln(1-h)]$$

Это частный случай кросс-энтропии, а не ограничение log-loss двумя классами.

## Как выдаётся штраф: по шагам

Для каждого студента $i$:

1. **Модель говорит:** $h_i = \sigma(w \cdot x_i + b)$ — вероятность «да» ([[sigmoid]])
2. **Берём вероятность правильного ответа:**
   - $y_i = 1$ (правда «да») → модель дала ему $h_i$
   - $y_i = 0$ (правда «нет») → модель дала ему $1 - h_i$
3. **Штраф** $= -\ln(\text{эта вероятность})$
4. **Ошибка модели** $J$ = среднее штрафов по всем $N$ студентам

## Пример: модель «Гриффиндор?», 4 студента

| Студент | Правда $y$ | Модель $h$ | Правильному ответу дали | Штраф              |
| ------- | ---------- | ---------- | ----------------------- | ------------------ |
| A       | 1          | 0.9        | $0.9$                   | $-\ln 0.9 = 0.11$  |
| B       | 1          | 0.2        | $0.2$                   | $-\ln 0.2 = 1.61$  |
| C       | 0          | 0.1        | $1 - 0.1 = 0.9$         | $-\ln 0.9 = 0.11$  |
| D       | 0          | 0.95       | $1 - 0.95 = 0.05$       | $-\ln 0.05 = 3.00$ |

$$J = \frac{0.11 + 1.61 + 0.11 + 3.00}{4} \approx 1.21$$

D — уверенная ошибка (95 % «да», а правда «нет») → больше всех тянет $J$ вверх → градиент сильнее всего двигает веса из-за него.

## Одной формулой

Шаг 2 («какую ветку брать») записывают без `if`, через $y$ как переключатель:

$$\text{штраф}_i = -\big[\, y_i \ln h_i + (1 - y_i) \ln(1 - h_i) \,\big]$$

- $y_i = 1$: вторая часть $\times 0$ исчезает → $-\ln h_i$
- $y_i = 0$: первая часть $\times 0$ исчезает → $-\ln(1 - h_i)$

$$J(w, b) = -\frac{1}{N} \sum_{i=1}^{N} \big[\, y_i \ln h_i + (1 - y_i) \ln(1 - h_i) \,\big]$$

## Почему $-\ln$

- $\ln$ от вероятности $\in (0, 1]$ отрицателен → минус делает штраф положительным
- $\ln 1 = 0$: идеальный ответ — ноль штрафа
- $\ln p \to -\infty$ при $p \to 0$: уверенная ошибка штрафуется без предела
- Глубже: среднее $-\ln$ = минус логарифм правдоподобия (вероятность увидеть все ответы $= \prod p_i$, логарифм → сумма) — тот же рецепт, что дал МНК → [[least-squares-from-likelihood]]

## Почему не MSE

MSE + сигмоида → градиент гаснет при уверенной ошибке. Разбор с картинкой → [[logistic-regression-gradient]].

## В коде

```python
h = sigmoid(X @ w + b)
eps = 1e-15                       # ln(0) = -inf → обрезаем
h = np.clip(h, eps, 1 - eps)
J = -np.mean(y * np.log(h) + (1 - y) * np.log(1 - h))
```

## Не только в бинарной классификации: LLM

В [[logreg-to-llm|LLM]] каждый токен словаря — отдельный класс. Модель выдаёт распределение вероятностей следующего токена; правильный ответ на обучающей позиции — токен из исходного текста. Это **категориальная кросс-энтропия**, с тем же штрафом $-\ln Q_{\text{правильный токен}}$.

Например, после «Столица Франции —» целевой токен «Париж» (предположим, он один): модель дала ему $0.8$ → штраф $-\ln 0.8\approx0.22$. При стандартном обучении предсказанию следующего токена штрафы усредняют по обучающим позициям.

Общее: повышаем вероятность наблюдаемого правильного ответа; меняется число классов — два ответа или весь словарь.
