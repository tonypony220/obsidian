# Оптимизаторы — Gradient Descent vs LBFGS

Оба ищут минимум loss-функции (точку с наименьшей ошибкой), но используют разную математику.

## Gradient Descent

Использует **первую производную** (градиент) — направление наклона. Шагает в сторону убывания с фиксированным шагом (learning rate). Знает только "куда", не знает "как далеко до дна".

Проблемы: фиксированный шаг может перескакивать минимум или ползти слишком медленно. Нужно вручную подбирать learning rate.

## LBFGS

Использует **первую + приближение второй производной** (гессиан). Вторая производная — как быстро меняется наклон, то есть кривизна. Это позволяет автоматически подбирать размер шага: большой на пологом участке, маленький у дна.

Полный гессиан для 768 измерений — матрица 768×768 (~590K чисел). LBFGS (L = limited memory) не считает его целиком, а приближает по последним нескольким шагам.

Для выпуклых функций (у логрегрессии loss выпуклый — одна яма без локальных минимумов) LBFGS математически гарантирует сходимость.

|                   | Gradient Descent              | LBFGS                      |
|-------------------|-------------------------------|-----------------------------|
| Математика        | 1-я производная               | 1-я + приближение 2-й       |
| Размер шага       | Фиксированный (вручную)       | Адаптивный (автоматически)  |
| Итераций          | Много                         | Мало                        |
