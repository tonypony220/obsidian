# Стратифицированный сплит

moc: [[ml-moc]]
next: [[centroid]] [[threshold-sweep]]

---

```
Исходные данные:  ████████░░  (80% irrel / 20% rel)
                       ↓ stratified split
Train (80%):      ████████░░  (80% / 20% ✓)
Test  (20%):      ████████░░  (80% / 20% ✓)

Без стратификации:
Test  (20%):      ██████████  (100% irrel — rel потеряны ✗)
```

При делении данных на train/test сохраняем пропорцию классов. Было 20% relevant / 80% irrelevant в исходных данных — будет ~20/80 и в train, и в test.

Без этого случайный сплит может дать test, где нет ни одного relevant — оценка модели теряет смысл.
