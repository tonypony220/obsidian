```
        ┌──────────────────────────────────────────────┐
        ▼                                              │
  w, b ──► h = σ(w·x + b) ──► промах h − y ──► градиент ──► шаг: w ← w − α·градиент
 (старт 0)  (все студенты)    (каждый студент)  (среднее)        (все параметры сразу)
```

**TL;DR:** обучение = цикл: посчитать $h$ для всех студентов → промахи $h - y$ → по одной частной производной на каждый параметр (среднее по студентам) → сдвинуть **все** параметры против своей производной → повторить. [[log-loss]] говорит, насколько плохо; [[logistic-regression-gradient]] — куда двигать; здесь — как это крутится.

## Цикл

Параметры: $w_1 \dots w_n, b$. Старт: все нули. Каждая эпоха ([[epochs]]):

1. **Предсказание** для каждого студента $i$: $h_i = \sigma(w \cdot x_i + b)$
2. **Промах:** $h_i - y_i$, где $y_i$ — правда из датасета (1 / 0)
3. **Градиент** — по одной частной производной на параметр, усреднённо по $N$ студентам:

$$\frac{\partial J}{\partial w_j} = \frac1N \sum_{i=1}^{N} (h_i - y_i)\, x_{ij} \qquad \frac{\partial J}{\partial b} = \frac1N \sum_{i=1}^{N} (h_i - y_i)$$

4. **Шаг** — все параметры одновременно, по старым значениям:

$$w_j \leftarrow w_j - \alpha \frac{\partial J}{\partial w_j} \qquad b \leftarrow b - \alpha \frac{\partial J}{\partial b}$$

## На числах: 2 студента, 2 признака

| Студент | $x_1$ | $x_2$ | $y$ |
|---|---|---|---|
| A | 2 | −1 | 1 |
| B | 1 | 1 | 0 |

Старт $w_1 = w_2 = b = 0$, $\alpha = 0.5$.

**Эпоха 1**

| | A | B |
|---|---|---|
| $z = w_1 x_1 + w_2 x_2 + b$ | 0 | 0 |
| $h = \sigma(z)$ | 0.5 | 0.5 |
| промах $h - y$ | −0.5 | +0.5 |

| Параметр | Частная производная (среднее A и B) | Новое значение |
|---|---|---|
| $w_1$ | $\frac{(-0.5)\cdot 2 + 0.5 \cdot 1}{2} = -0.25$ | $0 - 0.5 \cdot (-0.25) = 0.125$ |
| $w_2$ | $\frac{(-0.5)\cdot(-1) + 0.5 \cdot 1}{2} = 0.5$ | $0 - 0.5 \cdot 0.5 = -0.25$ |
| $b$ | $\frac{-0.5 + 0.5}{2} = 0$ | $0$ |

**Эпоха 2** — те же шаги с новыми весами:

| | A | B |
|---|---|---|
| $z$ | $0.125\cdot2 + (-0.25)(-1) = 0.5$ | $0.125 - 0.25 = -0.125$ |
| $h$ | 0.62 (было 0.5, правда 1 ✅ ближе) | 0.47 (было 0.5, правда 0 ✅ ближе) |

| Эпоха | $J$ ([[log-loss]]) |
|---|---|
| 1 | 0.693 |
| 2 | 0.553 |
| 3 | 0.460 |

$J$ падает, $h$ ползут к правильным ответам → это и есть обучение. Дальше — тысячи эпох, пока $J$ не перестанет заметно падать.

## Код

```python
w = np.zeros(n_features); b = 0.0
for epoch in range(n_epochs):
    h = sigmoid(X @ w + b)   # 1. предсказание всех студентов
    err = h - y              # 2. промахи
    dw = X.T @ err / N       # 3. все ∂J/∂w_j одной строкой
    db = err.mean()          #    ∂J/∂b
    w -= lr * dw             # 4. шаг, все параметры сразу
    b -= lr * db
```

- vs [[gradient-descent]] (линейная регрессия): + `sigmoid`, − двойка. Остальное то же
- $J$ в цикле не нужен — только для графика сходимости
- В dslr: ~13 признаков → 14 параметров, и этот цикл запускается 4 раза (по модели на факультет)
