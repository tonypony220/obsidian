```
 "Токенизация текста"
   │ tokenizer (BPE)
   ▼
 ["Ток","ен","изация"," текста"] → [8123, 421, 9917, 5530]
   │ lookup таблицы embeddings
   ▼
 [вектор, вектор, вектор, вектор] → модель
```

**TL;DR:** токенизация режет строку на кусочки из фиксированного словаря и заменяет их целыми числами; модель работает с этими id, а не с буквами.

- Токен ≠ слово. Современные токенизаторы (BPE, WordPiece, SentencePiece) делят на частые подслова: редкое слово = несколько токенов.
- Зачем подслова: словарь конечен, нет «неизвестных слов» (любое слово собирается из кусков), нет взрыва словаря как на уровне целых слов.
- Практические следствия:
  - Лимит [[context-window]] и цена LLM считаются в токенах, не в символах.
  - Русский и другие языки обычно дают больше токенов на то же содержание, чем английский.
  - Числа, код и опечатки режутся неожиданно, отсюда часть ошибок LLM со счётом букв.
- Токенизатор привязан к модели: id от одного не годятся для другого.
- Следующий шаг: каждый id превращается в вектор, см. [[embeddings]].
