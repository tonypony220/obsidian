Отношение: насколько изменился выход при маленьком изменении входа.

```
производная = изменение_выхода / изменение_входа
```

## Пример

`loss(w)`. Стоим в `w = 3`, loss = 10. Сдвигаем `w = 3.001`, loss = 9.998.

```
производная = (9.998 − 10) / (3.001 − 3) = −0.002 / 0.001 = −2
```

Производная = −2 → при сдвиге w на +1, loss изменится на −2. На графике это наклон кривой в данной точке.

## Правила дифференцирования (минимум для ML)

Всё выводится из одного вопроса: «сдвинул переменную на чуть-чуть $\Delta$ — на сколько сдвинулся результат?»

| Что | Производная | Почему | Пример |
|---|---|---|---|
| константа $c$ | $0$ | от сдвига переменной не меняется | $(7)' = 0$ |
| переменная $t$ | $1$ | сдвинул на $\Delta$ → результат на $\Delta$ | $(m)' = 1$ |
| число × переменная $c \cdot t$ | $c$ | сдвинул $t$ на 1 → результат на $c$ | $(5m)' = 5$ |
| сумма $f + g$ | $f' + g'$ | каждое слагаемое отдельно | $(5m + 7)' = 5 + 0 = 5$ |
| квадрат $t^2$ | $2t$ | см. ниже | $(m^2)' = 2m$ |
| вложенная $A(B(t))$ | $A'(B) \cdot B'(t)$ | [[chain-rule]] | $((3m)^2)' = 2 \cdot 3m \cdot 3$ |

Переменных несколько → берём по одной, остальные = константы → [[partial-derivative]].

### Почему $(t^2)' = 2t$

**Числами.** $t = 3$: $t^2 = 9$. Сдвиг $t = 3.001$: $t^2 = 9.006001$. Прирост $\approx 0.006$ на сдвиг $0.001$ → в $6$ раз $= 2 \cdot 3$ ✅. При $t = 10$ будет $20$: чем больше $t$, тем круче растёт квадрат.

**Картинкой.** $t^2$ — площадь квадрата со стороной $t$. Сторону удлинили на $\Delta$:

![[derivative-square.png]]

Добавились две полоски $t \cdot \Delta$ и крошечный уголок $\Delta^2$ (при маленьком $\Delta$ им пренебрегаем). Прирост $\approx 2t \cdot \Delta$ → производная $= 2t$.

## Вторая производная

То же действие, но применённое к первой производной — как быстро меняется наклон.

```
в w=1:     производная = −2
в w=1.001: производная = −1.99

вторая производная = (−1.99 − (−2)) / 0.001 = +10
```

Наклон быстро выравнивается → кривая загибается → дно близко.

## Аналогия с физикой

Производная — это обобщение формулы скорости. Та же математика, другие переменные:

```
физика                        ML
──────────────────────────────────────────
положение(t)                  loss(w)
скорость = d(положение)/dt    градиент = d(loss)/dw
ускорение = d(скорость)/dt    кривизна = d(градиент)/dw
```
