## Основы

- [[ml-task-types]] — классификация, регрессия, кластеризация

## Регрессия

- [[linear-regression]] — прямая θᵀx, MSE, градиентный спуск
- [[mse]] — среднеквадратичная ошибка, откуда квадрат и 1/2
- [[least-squares-from-likelihood]] — MSE выводится из гауссова шума (MLE)
- [[gradient-descent]] — производная ошибки по m, b и шаг спуска
- [[partial-derivative]] — наклон по одной переменной, остальные заморожены
- [[chain-rule]] — производная вложенной функции: внешняя × внутренняя

## Классификация

- [[logistic-regression]] — базовый классификатор, softmax для мультикласса
- [[why-linear-model]] — линейная форма = выбор; учатся только $w, b$; сигмоида выводится
- [[sigmoid]] — z → вероятность; logit, производная, tanh
- [[decision-boundary]] — прямая w·x + b = 0 разделяет классы
- [[log-loss]] — штраф −ln(вероятность правильного ответа)
- [[logistic-regression-gradient]] — цепочка, сокращение h(1−h), (h − y)·x
- [[logistic-regression-training]] — цикл обучения: промахи → градиент → шаг всех параметров
- [[svm]] — Support Vector Machine, максимизация отступа
- [[random-forest]] — ансамбль деревьев решений
- [[llm-vs-embeddings-classification]] — когда LLM, когда эмбеддинги

- [[ivf-index]] — кластерный индекс с поиском по выбранным спискам
