```
 Sales
   ▲
 25┤                               ●
   │                     ●       ╱
 20┤                           ╱
   │               ●         ╱  ●
 15┤                 ┆     ╱
   │           ●     ┆   ╱         ŷ = m·x + b
 10┤         ┆     ┆ ╱                m — наклон
   │         ┆     ╱                  b — где прямая
  5┤         ┆   ╱ ●                      пересекает ось
   │       ╱ ┆ ╱                          ┆ — ошибка (y − ŷ)
 b ┼─────╱───●────┬────┬────┬────┬──▶ Radio
   0         10   20   30   40   50
```

**TL;DR:** подбираем прямую `ŷ = θᵀx`, минимизируя средний квадрат ошибки; θ двигаем градиентным спуском против наклона ошибки.

## Модель

```
ŷ = θ₀ + θ₁·x₁ + … + θₙ·xₙ = θᵀx      (x₀ = 1 → θ₀ = bias)
```

- `θ₁` — наклон: насколько растёт `ŷ` при +1 к `x₁`
- `θ₀` — сдвиг: значение `ŷ` при всех `x = 0`

## Ошибка (loss) — MSE

```
MSE = 1/N · Σᵢ (yᵢ − ŷᵢ)²
```

Откуда формула и откуда иногда `1/2` → [[mse]].

| Кусок | Зачем |
|---|---|
| `ŷᵢ − yᵢ` | промах на i-м примере |
| `²` | знак не важен, большие промахи штрафуются сильнее, функция гладкая |
| `1/N` | среднее, не зависит от размера датасета |

## Градиент

Производная `J` по каждому весу ([[derivative]], правило цепочки):

```
∂J/∂θⱼ = 1/m · Σᵢ (ŷᵢ − yᵢ) · xᵢⱼ
```

Смысл: `ошибка × вклад признака`. Признак, который сильно участвовал в большой ошибке, получает большую поправку.

## Градиентный спуск

```
повторять (эпохи):
    θⱼ := θⱼ − α · ∂J/∂θⱼ     для всех j одновременно
```

- Минус — идём против роста ошибки, вниз по склону
- `α` — [[learning-rate]]: мал → медленно, велик → прыгаем через минимум и расходимся
- Одна эпоха = один проход по данным ([[epochs]])

## Нормализация признаков

Признаки разного масштаба (`км` 0..240000 vs `θ`) → градиенты разного порядка → один `α` не подходит всем.

```
z-score:  x' = (x − mean) / std
min-max:  x' = (x − min) / (max − min)
```

После обучения на нормализованных данных → либо нормализовать вход при предсказании теми же mean/std, либо пересчитать θ обратно.

## Мост к классификации

[[logistic-regression]] = та же `θᵀx`, но через сигмоиду + log-loss вместо MSE. Градиент получается **той же формы** `1/m · Σ(h − y)·x` — код спуска почти не меняется.

## Не только в ML

- Физика: МНК для подгонки экспериментальных точек
- Эконометрика: регрессия спроса на цену
- Нейросети: каждый линейный слой = `Wx + b`, обучается тем же градиентом
- Численные методы: градиентный спуск минимизирует любую гладкую функцию

Общее везде: параметры двигаются против градиента ошибки, пока он не станет ≈ 0.
