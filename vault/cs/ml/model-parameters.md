# Параметры модели

moc: [[ml-moc]]
next:
- [[quantization]]

---

```
 обучение:  тексты ──► подкрутка чисел ──► [ w1 w2 w3 ... w27_000_000_000 ]
                                             └── «27B» = 27 млрд параметров
 всё «знание» модели = эти числа, больше внутри ничего нет
```

**TL;DR:** параметры (веса) — числа, которые подбираются при обучении; больше параметров = больше ёмкость модели, но больше памяти и вычислений на каждый токен.

- «27B» = 27 миллиардов весов. Всё, что модель умеет, записано только в них.
- Ёмкость: больше параметров → больше закономерностей, тоньше различение похожих случаев. Аналогия: конспект на 10 страниц vs учебник на 500.
- Цена размера: каждый вес надо хранить (память GPU) и перемножать при генерации каждого токена (скорость).
- Память под веса = число параметров × байт на параметр. 31B в bf16 (2 байта) ≈ 62 GB.
- Сравнивать размеры можно только внутри одного поколения и семейства: свежая модель поменьше может обойти старую побольше.
- Размер ≠ активные параметры: у [[moe-mixture-of-experts]] хранится всё, считается часть.
- Тот же вес можно записать грубее: [[quantization]].
