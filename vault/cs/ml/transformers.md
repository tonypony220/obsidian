```
 токены:  Кот  сел  на  диван  потому  что  он
           ▲─────────────────────────────────┘
          attention: каждый токен смотрит на все остальные
          и решает, на какие обращать внимание («он» → «кот»)
```

**TL;DR:** transformer обрабатывает все токены последовательности параллельно, а механизм attention позволяет каждому токену учитывать любые другие.

- Вход: [[tokenization]] → [[embeddings]] токенов + информация о позиции.
- Слой = attention (кто на кого смотрит) + небольшая сеть над каждым токеном; слоёв десятки.
- Почему победил RNN: параллельное обучение на GPU и прямая связь между далёкими токенами.
- LLM (GPT-подобные) предсказывают следующий токен по предыдущим; текст рождается циклом «предскажи токен → добавь → повтори».
- Цена attention растёт с длиной последовательности (квадратично по базовой схеме), отсюда лимит [[context-window]].
- Модель знает только то, что в весах (обучение) и в текущем контексте. Отсюда три способа дать ей знания: [[prompting-vs-rag-vs-finetuning]].
- Encoder-модели (BERT-подобные) дают эмбеддинги и классификацию; decoder-модели (GPT-подобные) генерируют текст.
