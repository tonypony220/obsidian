```
  2 класса:   z  ═══════════════  ln( p / (1−p) )          логит в строгом смысле
              │
  K классов:  z_G − z_H  ═══════  ln( p_G / p_H )          шансы спрятаны в разнице
              │
  жаргон ML:  «logits» = все z до softmax                  просто сырые баллы
```

**TL;DR:** Логит в математике — это $\ln$ шансов. В ML «логитами» называют любые сырые баллы модели до [[softmax]]. Шансы при этом никуда не делись: разница двух баллов равна $\ln$ отношения их вероятностей.

## Значение 1: математическое

$$\text{logit}(p) = \ln \frac{p}{1 - p}$$

Шансы $\frac{p}{1-p}$ — во сколько раз «да» вероятнее «нет». Пример: $p = 0.8$, шансы $= 4$, логит $= \ln 4 \approx 1.39$.

Логит — обратная функция к [[sigmoid]]: сигмоида $z \to p$, логит $p \to z$. Вывод → [[sigmoid#Шаг 2. Подобрать диапазон]].

## Значение 2: жаргон ML

«Logits» = выход модели до softmax, по баллу на класс. Так пишут в PyTorch (`CrossEntropyLoss(logits, ...)`), в статьях, про LLM. Здесь ни одна формула шансов явно не считается.

## Где спрятаны шансы

Отдельный балл смысла не имеет: прибавишь ко всем $+10$ — проценты те же ([[softmax#Важны только разницы баллов]]). Смысл есть у **разницы**:

$$z_a - z_b = \ln \frac{p_a}{p_b}$$

### Откуда формула (3 шага)

**1. Оба процента по softmax.** Знаменатель $S = \sum_j e^{z_j}$ у всех классов **общий**:

$$p_a = \frac{e^{z_a}}{S}, \qquad p_b = \frac{e^{z_b}}{S}$$

**2. Поделить один на другой** — $S$ сокращается:

$$\frac{p_a}{p_b} = \frac{e^{z_a}/S}{e^{z_b}/S} = \frac{e^{z_a}}{e^{z_b}}$$

Числа: $(2.72/4.09) / (1/4.09) = 2.72/1$. Следствие: отношение двух классов **не зависит от остальных** классов — сколько бы их ни было.

**3. Деление степеней = вычитание показателей** ($e^5/e^3 = e^2$), потом снять экспоненту через $\ln$:

$$\frac{p_a}{p_b} = e^{z_a - z_b} \iff \ln\frac{p_a}{p_b} = z_a - z_b$$

| разница баллов | отношение вероятностей |
|---|---|
| 0 | $e^0 = 1$ — поровну |
| 1 | $e \approx 2.7$ |
| 2 | $e^2 \approx 7.4$ |
| −1 | $\approx 0.37$ — в 2.7 раза менее вероятен |

Отсюда же: $+10$ ко всем баллам не меняет разниц → не меняет отношений → не меняет процентов.


Пример ([[softmax-regression-step]]): баллы G $= 1$, H $= 0$, проценты $0.66$ и $0.24$:
- разница баллов $= 1$
- $\ln(0.66 / 0.24) = \ln 2.75 \approx 1$ ✅

«На 1 балл выше» = «в $e \approx 2.7$ раза вероятнее». Это шансы, только не «да против нет», а «G против H».

## Почему жаргон пошёл отсюда

Два класса: «да» с баллом $z$, «нет» с баллом $0$ (один балл можно зафиксировать — важны только разницы). Тогда

$$z - 0 = \ln \frac{p_{\text{да}}}{p_{\text{нет}}} = \ln \frac{p}{1 - p}$$

— ровно строгий логит. В многоклассовом случае название перенесли на все баллы, хотя логарифм шансов теперь только их разности.
