**TL;DR:** $\sigma(z) = \frac{1}{1 + e^{-z}}$ сжимает любое число $z = w x + b$ в $(0, 1)$ → выход линейной модели становится вероятностью. Именно она, потому что линейная модель на самом деле предсказывает **логарифм шансов**, а сигмоида — его обратная функция.

## Зачем

Линейная часть $z = w x + b$ даёт любое число ($-50$, $3$, $1000$). Для классификации нужна вероятность «да» $\in (0, 1)$:

$$h = \sigma(w x + b)$$

## Как работает формула

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

| $z$ | $e^{-z}$ | $\sigma(z)$ | смысл |
|---|---|---|---|
| $+5$ | $\approx 0.007$ | $\frac{1}{1.007} \approx 0.99$ | точно да |
| $0$ | $1$ | $\frac{1}{2} = 0.5$ | не знаю |
| $-4$ | $\approx 55$ | $\frac{1}{56} \approx 0.02$ | точно нет |

- Весь трюк в $e^{-z}$: при большом $z$ он исчезает → $1$; при отрицательном $z$ он огромный → $\approx 0$
- Порог решения $h = 0.5$ ⇔ $z = 0$ ⇔ $w x + b = 0$ — это и есть **граница решения**: прямая (плоскость), разделяющая классы

## Почему именно сигмоида: шансы

**Шансы** (odds) — как у букмекеров: $\text{odds} = \frac{p}{1-p}$. $p = 0.8$ → шансы $4 : 1$.

| $p$ | odds $= \frac{p}{1-p}$ | $\log(\text{odds})$ |
|---|---|---|
| 0.5 | 1 | 0 |
| 0.8 | 4 | +1.39 |
| 0.2 | 0.25 | −1.39 |
| → 1 | → ∞ | → +∞ |
| → 0 | → 0 | → −∞ |

$\log(\text{odds})$ (**logit**) принимает любые значения от $-\infty$ до $+\infty$ — как и $w x + b$. Поэтому договариваемся: линейная модель предсказывает logit:

$$w x + b = \log \frac{p}{1 - p}$$

Выражаем $p$ → получается сигмоида:

$$\frac{p}{1-p} = e^{z} \;\Rightarrow\; p = \frac{e^{z}}{1 + e^{z}} = \frac{1}{1 + e^{-z}} = \sigma(z)$$

Отсюда и название: **логистическая** регрессия = линейная регрессия на логарифме шансов. Смысл веса: $w = +1$ → при $x + 1$ шансы «да» растут в $e \approx 2.7$ раза.

## Производная

$$\sigma'(z) = \sigma(z)\,\big(1 - \sigma(z)\big)$$

- Выражается через саму сигмоиду → дёшево считать
- Максимум $0.25$ в $z = 0$, на краях → 0 (кривая там плоская)
- Понадобится в цепочке для градиента log-loss → [[chain-rule]]

## tanh

![[sigmoid-vs-tanh.png]]

$$\tanh(z) = \frac{e^{z} - e^{-z}}{e^{z} + e^{-z}} = 2\,\sigma(2z) - 1$$

| | $\sigma$ | $\tanh$ |
|---|---|---|
| диапазон | $(0, 1)$ | $(-1, 1)$ |
| в нуле | $0.5$ | $0$ (центрирован) |
| макс. производная | $0.25$ | $1$ |
| производная | $\sigma(1-\sigma)$ | $1 - \tanh^2$ |
| где | выход бинарного классификатора (вероятность) | скрытые слои нейросетей, RNN/LSTM |

- Та же S-кривая: сдвинута и растянута, по сути одна функция
- tanh центрирован в 0 → в нейросетях градиенты лучше сбалансированы; но вероятностью быть не может
- Для dslr нужен **только** $\sigma$: на выходе вероятность факультета
- Общая беда обеих: на краях производная ≈ 0 → градиент «затухает» (vanishing gradient) → в глубоких сетях их вытеснил ReLU
