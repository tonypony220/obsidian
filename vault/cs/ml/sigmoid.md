**TL;DR:** $\sigma(z) = \frac{1}{1 + e^{-z}}$ сжимает любое число $z = w x + b$ в $(0, 1)$ → выход линейной модели становится вероятностью. Именно она, потому что линейная модель на самом деле предсказывает **логарифм шансов**, а сигмоида — его обратная функция.

## Зачем

Линейная часть $z = w x + b$ даёт любое число ($-50$, $3$, $1000$). Для классификации нужна вероятность «да» $\in (0, 1)$:

$$h = \sigma(w x + b)$$

## Что такое $e$

Константа, как $\pi$: $e \approx 2.718$. $e^z$ — просто «2.718 в степени $z$»:

| $z$ | $e^z$ |
|---|---|
| $5$ | $\approx 148$ |
| $0$ | $1$ |
| $-5$ | $\approx 0.007$ (крошечное, но всегда $> 0$) |

Почему $e$, а не 2 или 10: сработало бы любое основание (поменялись бы только веса). $e$ берут, потому что $(e^z)' = e^z$ → формулы градиента короче.

## Как работает формула

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

| $z$ | $e^{-z}$ | $\sigma(z)$ | смысл |
|---|---|---|---|
| $+5$ | $\approx 0.007$ | $\frac{1}{1.007} \approx 0.99$ | точно да |
| $0$ | $1$ | $\frac{1}{2} = 0.5$ | не знаю |
| $-4$ | $\approx 55$ | $\frac{1}{56} \approx 0.02$ | точно нет |

- Весь трюк в $e^{-z}$: при большом $z$ он исчезает → $1$; при отрицательном $z$ он огромный → $\approx 0$
- Порог $h = 0.5$ ⇔ $z = 0$ ⇔ $w x + b = 0$ → [[decision-boundary]]

### Зачем минус в степени

Без минуса, $\frac{1}{1 + e^{z}}$: $z = 5 \to \frac{1}{149} \approx 0.007$, $z = -5 \to 0.99$ — кривая **зеркальная**, большое $z$ = «нет». Минус нужен, чтобы **большое $z$ = «да»**.

## Что такое $z = w x + b$

Та же формула прямой, что в [[linear-regression]] ($m$ переименовали в $w$). Много признаков → $z = w_1 x_1 + w_2 x_2 + \dots + b$.

$z$ — **очки «за» и «против»**: каждый признак добавляет очки в пользу «да» или «нет». Пример, модель «Гриффиндор?»:

- $w_1 = +0.8$ (защита от тёмных искусств), $w_2 = -0.5$ (зельеварение), $b = -1$
- студент $x_1 = 5,\ x_2 = 2$: $z = 4 - 1 - 1 = 2$ → $\sigma(2) \approx 0.88$

## Почему именно сигмоида: шансы (пошагово)

Для реализации dslr не обязательно — отвечает на «почему именно эта функция».

### Шаг 1. Шансы

**Вероятность** $p$ — доля «да» среди всех. **Шансы** (odds) — во сколько раз «да» вероятнее «нет»:

$$\text{odds} = \frac{p}{1 - p} = \frac{\text{вероятность да}}{\text{вероятность нет}}$$

| $p$ | да : нет | odds |
|---|---|---|
| 0.5 | 5 : 5 | 1 — поровну |
| 0.8 | 8 : 2 | 4 — «да» в 4 раза вероятнее |
| 0.2 | 2 : 8 | 0.25 |
| 0.99 | 99 : 1 | 99 |

Как у букмекеров: «шансы 4 к 1».

### Шаг 2. Подобрать диапазон

$z = w x + b$ — любое число $(-\infty, +\infty)$. С чем его связать?

| Величина            | Диапазон             | Годится?               |
| ------------------- | -------------------- | ---------------------- |
| $p$                 | $(0, 1)$             | нет                    |
| odds                | $(0, +\infty)$       | нет, нет отрицательных |
| $\ln(\text{odds})$ | $(-\infty, +\infty)$ | ✅                      |

$\ln$ растягивает $(0, \infty)$ на всю прямую: odds $= 1 \to 0$, больше 1 → плюс, меньше 1 → минус.

Договариваемся: **очки $z$ = логарифм шансов** (logit):

$$z = \ln \frac{p}{1 - p}$$

### Шаг 3. Убрать логарифм

$\ln$ и $e^{(\cdot)}$ — взаимно обратные, отменяют друг друга (как $\times$ и $\div$):

$$\ln(\text{odds}) = z \iff \text{odds} = e^{z}$$

Аналогия: $\log_{10}(x) = 2 \iff x = 10^2 = 100$. Здесь то же, основание $e$: $\ln = \log_e$ (натуральный логарифм; в ML-текстах часто пишут просто $\log$, подразумевая $\ln$).

### Шаг 4. Выразить $p$

$$\frac{p}{1-p} = e^z \;\Rightarrow\; p = e^z - e^z p \;\Rightarrow\; p\,(1 + e^z) = e^z \;\Rightarrow\; p = \frac{e^z}{1 + e^z}$$

Делим числитель и знаменатель на $e^z$:

$$p = \frac{1}{1 + e^{-z}} = \sigma(z)$$

**Сигмоида = перевод шансов, которые предсказывает модель, обратно в вероятность.** Отсюда название: **логистическая** регрессия = линейная регрессия на логарифме шансов.

### Проверка числами

$z = 1.39$: odds $= e^{1.39} \approx 4$ → $p = \frac{4}{4 + 1} = 0.8$; и $\sigma(1.39) = \frac{1}{1 + 0.25} = 0.8$ ✅

Смысл веса: $w = +1$ → при $x + 1$ очки $+1$ → шансы «да» × $e \approx 2.7$.

## Выбор, а не случайность

Цепочка «что из чего следует»:

$$\underbrace{z = w x + b \in (-\infty, +\infty)}_{\text{дано: линейные очки}} \;\xrightarrow{\text{выбор}}\; z = \ln\frac{p}{1-p} \;\xrightarrow{e^{(\cdot)}}\; \frac{p}{1-p} = e^{z} \;\xrightarrow{\text{алгебра}}\; p = \frac{1}{1 + e^{-z}} = \sigma(z)$$

- Почему вообще линейная $w x + b$ — тоже выбор → [[why-linear-model]]
- Решение одно — **выбор**: «очки = логарифм шансов». Дальше только алгебра → сигмоида неизбежна
- Можно было иначе: любая гладкая $(-\infty, \infty) \to (0, 1)$. Пример — **probit**: $p = \Phi(z)$, накопленный гауссов колокол; почти та же S-кривая
- Почему стандарт — log-odds:
  1. **Понятные веса**: $w = 1$ → при $x + 1$ шансы × $e$
  2. **Простой градиент**: с log-loss сокращается до $(h - y)\,x$
  3. **Следует из статистики**: ответ да/нет (Бернулли) + правдоподобие → log-odds сам («каноническая связь»), как гауссов шум → МНК ([[least-squares-from-likelihood]])
- История: S-функция — Ферхюльст, 1838, рост населения («logistic»); Берксон, 1944, — линейная модель на log-odds («logit»)

## Производная

$$\sigma'(z) = \sigma(z)\,\big(1 - \sigma(z)\big)$$

- Выражается через саму сигмоиду → дёшево считать
- Максимум $0.25$ в $z = 0$, на краях → 0 (кривая там плоская)
- Понадобится в цепочке для градиента log-loss → [[chain-rule]]

## tanh

![[sigmoid-vs-tanh.png]]

$$\tanh(z) = \frac{e^{z} - e^{-z}}{e^{z} + e^{-z}} = 2\,\sigma(2z) - 1$$

| | $\sigma$ | $\tanh$ |
|---|---|---|
| диапазон | $(0, 1)$ | $(-1, 1)$ |
| в нуле | $0.5$ | $0$ (центрирован) |
| макс. производная | $0.25$ | $1$ |
| производная | $\sigma(1-\sigma)$ | $1 - \tanh^2$ |
| где | выход бинарного классификатора (вероятность) | скрытые слои нейросетей, RNN/LSTM |

- Та же S-кривая: сдвинута и растянута, по сути одна функция
- tanh центрирован в 0 → в нейросетях градиенты лучше сбалансированы; но вероятностью быть не может
- Для dslr нужен **только** $\sigma$: на выходе вероятность факультета
- Общая беда обеих: на краях производная ≈ 0 → градиент «затухает» (vanishing gradient) → в глубоких сетях их вытеснил ReLU
