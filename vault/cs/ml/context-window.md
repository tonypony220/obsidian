# Контекстное окно

```
 ┌──────────────── context window (N токенов) ────────────────┐
 │ system prompt │ история │ найденные документы │ вопрос │ ответ │
 └─────────────────────────────────────────────────────────────┘
   за границей окна модель ничего не видит
```

**TL;DR:** контекстное окно — максимальное число токенов (вход плюс ответ), которое модель видит за один вызов; всё, что модель должна знать «сейчас», обязано в него поместиться.

- Единица измерения — токены, не символы: [[tokenization]].
- Модель не помнит прошлые вызовы. Память чата создаёт приложение, заново присылая историю.
- Не влезает → отбрасывают старое, сжимают в summary или выбирают нужное через [[semantic-search]].
- Длинное окно не гарантирует равное внимание: модель хуже использует информацию из середины длинного контекста, и каждый лишний токен стоит денег и задержки.
- Это главное ограничение, определяющее выбор между вставкой данных в промпт, RAG и обучением: [[prompting-vs-rag-vs-finetuning]].
