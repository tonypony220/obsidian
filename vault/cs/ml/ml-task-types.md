```
 классификация      регрессия          кластеризация
 вход → класс       вход → число       входы → группы (без меток)
  ● ●  ○ ○           ·  ·  ·/           ● ●   ○ ○
  ● ● | ○ ○          · · · /            ●●    ○○ ○
   граница        прямая/кривая       группы находит сама модель
```

**TL;DR:** тип задачи определяется выходом: категория (классификация), число (регрессия) или структура без меток (кластеризация).

| Задача | Выход | Метки в данных | Примеры |
|---|---|---|---|
| Классификация | дискретный класс | да | спам / не спам, тема текста |
| Регрессия | непрерывное число | да | цена, время доставки |
| Кластеризация | номер группы | нет | сегменты пользователей, группировка документов |

- Классификация и регрессия = supervised (есть правильные ответы). Кластеризация = unsupervised.
- Одна и та же модель часто умеет обе стороны: [[logistic-regression]] классифицирует, линейная регрессия предсказывает число.
- Выбор метрики следует из типа: для классификации [[confusion-matrix]], precision, [[recall]]; для регрессии ошибка в единицах цели (MAE, RMSE).
- Текст сводится к тем же задачам через embeddings: text classification = классификация, группировка похожих документов = кластеризация.

## Концепция шире

- Статистика: зависимая переменная категориальная или количественная — тот же выбор.
- Рекомендации: «оценить рейтинг» (регрессия) vs «выбрать категорию» (классификация).
- Диагностика: «болен / здоров» vs «уровень показателя».

Общее везде: тип выхода определяет функцию потерь и способ оценки.
