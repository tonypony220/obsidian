# MSE — среднеквадратичная ошибка

back: [[linear-regression]]

---

```
  ошибка e = y − ŷ          штраф e²
                              ▲
   y ●                      25┤●                     ●
     ┆ e = +3               16┤  ●                 ●
   ŷ ─────── прямая          9┤    ●             ●
     ┆ e = −2                4┤      ●         ●
   y ●                       1┤        ●     ●
                             0┼──────────●─────────▶ e
                             -5         0          +5
   знак разный →              парабола: знак исчез,
   в сумме гасятся            большие промахи дороже
```

**TL;DR:** MSE = среднее квадратов промахов; одно число «насколько модель плоха». Квадрат убирает знак и делает функцию гладкой (есть производная везде).

## Формула — сборка по шагам

| Шаг | Выражение | Зачем |
|---|---|---|
| 1. промах на точке | `eᵢ = yᵢ − ŷᵢ` | насколько прямая мимо |
| 2. убрать знак | `eᵢ²` | `+3` и `−3` не должны гаситься в сумме |
| 3. сложить по всем | `Σ eᵢ²` | общая плохость |
| 4. усреднить | `1/N · Σ eᵢ²` | не зависит от числа точек |

```
MSE = 1/N · Σᵢ (yᵢ − ŷᵢ)²
```

Пример: промахи `+3, −2, +1` → `(9 + 4 + 1)/3 = 4.67`.

## Почему квадрат, а не модуль `|e|`

- `|e|` (MAE) тоже убирает знак, но в 0 у него излом → производной нет; градиентный спуск спотыкается
- `e²` гладкая парабола → производная `2e` везде, чем дальше от цели, тем сильнее тянет
- Минус: выбросы (`e = 10` → штраф 100) доминируют

## Откуда `1/2` (вариант `1/2N`)

```
MSE  = 1/N  · Σ e²   →  производная: 1/N · Σ 2e·(…)    ← висит двойка
J    = 1/2N · Σ e²   →  производная: 1/N · Σ  e·(…)    ← двойка сократилась
```

- Чистая косметика: минимум в той же точке (умножение на константу не двигает дно)
- Двойку всё равно «съедает» [[learning-rate]]: `α·2` vs `α` — просто другой шаг
- В ML Cheatsheet встречаются обе: `1/N` в простой регрессии, `1/2N` в многомерной

## Глубже: откуда вообще квадрат (статистика)

Если считать шум данных нормальным (гаусс), то максимизация правдоподобия ⇔ минимизация `Σ e²`. Квадрат — не произвол, а следствие предположения о шуме. Аналогично для классификации из правдоподобия берётся log-loss → [[logistic-regression]].
