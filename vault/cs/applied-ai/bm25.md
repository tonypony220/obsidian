# BM25

```
запрос: "scope screening"

          "scope"      "screening"
  D1      ×10          –            score 0.57
  D2      ×1           ×1           score 1.67   ← 1-е место
  D3      ×2           –            score 0.40
  D4      ×1           –            score 0.29

  "screening" редкое → весит в 5 раз больше, чем частое "scope"
  10 повторов "scope" не перебивают одно редкое слово
```

**TL;DR:** BM25 (Best Matching 25) — метод [[retrieval]] по словам: каждому документу считает score по совпадению слов запроса, потом документы сортируются по score. Редкие слова весят больше, повторы дают всё меньше прироста, длинные документы штрафуются.

## К чему относится

Семейство **sparse / lexical retrieval** (поиск по словам, без нейросетей). Родители и соседи: Boolean → TF-IDF → **BM25** → SPLADE, подробно в [[retrieval]]. BM25 — улучшенный TF-IDF и стандарт по умолчанию в Elasticsearch, OpenSearch, Lucene.

## Термины

| Сокращение | Полностью | Смысл |
|---|---|---|
| term | term | слово (после приведения к нижнему регистру и т.п.) |
| TF | term frequency | сколько раз слово встретилось в документе |
| DF | document frequency | в скольких документах корпуса есть слово |
| IDF | inverse document frequency | «обратная» DF: чем реже слово по корпусу, тем больше IDF |
| avgdl | average document length | средняя длина документа в корпусе |

## Пример с числами

Корпус: 5 документов, одинаковой длины. Запрос: `scope screening`.
- `scope` есть в 4 документах из 5 → частое → IDF = **0.29**
- `screening` есть в 1 документе → редкое → IDF = **1.39**

Вклад слова = IDF × (TF с насыщением). Насыщение при $k_1 = 1.2$:

| TF (повторов) | 1 | 2 | 5 | 10 |
|---|---|---|---|---|
| множитель | 1.00 | 1.38 | 1.77 | 1.96 |

10 повторов дают меньше чем в 2 раза больше, чем 1.

| Документ | содержит | score |
|---|---|---|
| D2 | scope×1, screening×1 | 0.29×1.00 + 1.39×1.00 = **1.67** |
| D1 | scope×10 | 0.29×1.96 = 0.57 |
| D3 | scope×2 | 0.29×1.38 = 0.40 |
| D4 | scope×1 | 0.29 |
| D5 | ничего | 0 |

**Где используется score:** только для сортировки. Выдача = D2, D1, D3, D4. Если берём top-2 → в LLM уйдут D2 и D1. Абсолютное число (1.67) само по себе ничего не значит и между разными запросами несравнимо.

## Формула

$$
\text{score}(D, Q) = \sum_{q \in Q} \text{IDF}(q) \cdot \frac{\text{TF}(q,D)\,(k_1+1)}{\text{TF}(q,D) + k_1\left(1 - b + b\,\frac{|D|}{\text{avgdl}}\right)}
$$

$$
\text{IDF}(q) = \ln\left(\frac{N - \text{DF}(q) + 0.5}{\text{DF}(q) + 0.5} + 1\right)
$$

- сумма по словам запроса: score = сумма вкладов слов
- $N$ — число документов; $|D|$ — длина документа
- $k_1 \approx 1.2$ — скорость насыщения. При $\text{TF} \to \infty$ дробь упирается в $k_1 + 1$
- $b \approx 0.75$ — сила штрафа за длину. Документ вдвое длиннее среднего → знаменатель больше → вклад меньше. Зачем: в 200-страничном отчёте слово встретится случайно

## Сильные и слабые стороны

| Хорошо | Плохо |
|---|---|
| точные коды и термины: `ISO 14001`, `Scope 3`, `GO-2024-17` | синонимы: «электроэнергия» ≠ «electricity» |
| без обучения, быстро (inverted index: слово → список документов) | другие языки: `elektriciteit` не совпадёт с `electricity` |
| объяснимо: видно, какое слово дало очки | перефразы и смысл |

Поэтому его комбинируют с [[dense-retrieval-embeddings]] — см. [[hybrid-search-rrf]].
