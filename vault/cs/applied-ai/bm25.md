# BM25

moc: [[applied-ai-moc]]
next:
- [[dense-retrieval-embeddings]]
- [[hybrid-search-rrf]]

---

```
запрос: "scope 3 screening"

          inverted index
  "scope"     → doc1, doc4, doc7, ... (частое → мало весит)
  "screening" → doc4                  (редкое → много весит)

  score(doc4) = вклад("scope") + вклад("screening")
                   ↑ насыщается: 10 повторов ≈ ненамного лучше 3
                   ↑ штраф за длинный документ
```

**TL;DR:** BM25 ранжирует документы по совпадению *слов* запроса: редкие слова весят больше, повторы насыщаются, длинные документы штрафуются. Смысла не понимает, но точные термины и коды находит лучше всего.

## Интуиция по трём частям

1. **Редкость слова (IDF).** Слово, которое есть почти везде («the», «report»), ничего не различает. Слово из 1 документа из 63 — сильный сигнал.
2. **Частота в документе (TF) с насыщением.** 1 упоминание → много очков, 2 → чуть больше, 20 → почти столько же. Иначе документ, где слово просто повторяется, выигрывал бы.
3. **Нормализация по длине.** В 200-страничном отчёте любое слово встретится случайно → длинным документам очки урезаются.

## Формула

$$
\text{score}(D, Q) = \sum_{q \in Q} \text{IDF}(q) \cdot \frac{f(q,D)\,(k_1+1)}{f(q,D) + k_1\left(1 - b + b\,\frac{|D|}{\text{avgdl}}\right)}
$$

- $f(q,D)$ — сколько раз слово $q$ встретилось в документе $D$
- $|D|/\text{avgdl}$ — длина документа относительно средней
- $k_1 \approx 1.2$ — как быстро насыщается TF; $b \approx 0.75$ — сила штрафа за длину
- $\text{IDF}(q) = \ln\left(\frac{N - n_q + 0.5}{n_q + 0.5} + 1\right)$, $N$ — всего документов, $n_q$ — сколько содержат $q$

Дробь при $f \to \infty$ стремится к $k_1+1$ — это и есть насыщение.

## Как работает быстро

Inverted index: слово → список документов, где оно есть. Запрос из 3 слов трогает только 3 списка, а не весь корпус. Так работают Elasticsearch, Lucene, OpenSearch.

## Сильные / слабые стороны

| ✅ | ❌ |
|---|---|
| точные термины, коды, номера: `ISO 14001`, `Scope 3`, `GO-2024-17` | синонимы: «электроэнергия» ≠ «electricity» ≠ «elektriciteit» |
| без обучения, дёшево, объяснимо | перефразы, смысл |
| предсказуемо | опечатки, разные формы слова (частично лечит стемминг) |

Для задачи с dataroom на 3 языках BM25 один не справится — но он ловит точные идентификаторы, которые [[dense-retrieval-embeddings]] размывает. Отсюда [[hybrid-search-rrf]].
