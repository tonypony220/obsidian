```
            запрос
           ┌──┴──┐
         BM25   dense
          │       │
  ранги: A1 B2   B1 C2
         C3 D4   A3 E4
           └──┬──┘
         RRF: Σ 1/(60 + rank)
              │
         B, A, C, E, D   → (дальше reranker)
```

**TL;DR:** Запускаем [[bm25]] и [[dense-retrieval-embeddings]] параллельно и склеиваем их списки. Склеиваем по *месту в списке* (RRF), а не по очкам, потому что очки двух систем несравнимы.

## Зачем два поиска

У них ошибки разной природы:
- BM25 промахивается на синонимах и других языках
- dense промахивается на точных кодах, числах, редких терминах

Документ, который пропустил один, часто находит другой → recall растёт.

## Почему нельзя просто сложить очки

BM25 выдаёт, скажем, 14.7, косинус — 0.83. Шкалы разные, распределения разные, зависят от запроса. Нормализовать можно, но хрупко.

## RRF — Reciprocal Rank Fusion

Берём только ранг документа в каждом списке:

$$
\text{RRF}(d) = \sum_{s \in \text{systems}} \frac{1}{k + \text{rank}_s(d)}, \quad k = 60
$$

- 1-е место даёт $1/61$, 10-е — $1/70$: верх списка важнее, но не подавляюще
- $k$ сглаживает: без него 1-е место ($1/1$) забивало бы всё остальное
- нет в списке → вклад 0
- документ на 3-м месте в обоих обгонит документ, который 1-й в одном и отсутствует в другом → награда за согласие систем

Пример (из схемы): B = 1/62 + 1/61 ≈ 0.0325; A = 1/61 + 1/63 ≈ 0.0323; C = 1/63 + 1/62 ≈ 0.0320.

## Где в пайплайне

Hybrid + RRF — первый этап «набрать кандидатов с высоким recall», дальше [[reranking-cross-encoder]] точно упорядочивает top-50. Но всё ещё top-k: потерянное здесь не вернёт никакой следующий шаг.

## Концепция шире

- **Ансамбли в ML:** голосование моделей с некоррелированными ошибками точнее любой одной
- **Метапоиск:** агрегаторы склеивали выдачи нескольких поисковиков именно по рангам
- **Выборы:** ранжированное голосование (Borda count) — та же сумма по позициям
- **Мониторинг:** алерт по согласию нескольких независимых сигналов надёжнее одного порога

Общее везде: когда шкалы несравнимы, сравнивай порядок; когда ошибки независимы, согласие источников снижает их.
