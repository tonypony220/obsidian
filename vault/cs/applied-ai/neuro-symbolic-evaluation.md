```
  NEURO (LLM) — понимает текст         SYMBOLIC (код) — решает
  ───────────────────────────         ───────────────────────
  PDF/Excel ─▶ извлечь факты ─▶ JSON ─▶ required = {1..15}
              {screened: [1,3,5..15],   missing = required - screened
               page: 7}                 → {2, 4}
                                        status = "not met"
```

**TL;DR:** Разделить работу: нейросеть (neuro) только читает текст и превращает его в структурированные факты, а обычный код (symbolic — правила, логика, арифметика) принимает решение. LLM плохо и непредсказуемо считает и проверяет полноту множеств, код — идеально.

## К чему относится

Не метод поиска, а способ **принимать решение** после того, как факты найдены любым методом ([[retrieval]], [[exhaustive-scan]]). Большая область AI: neuro-symbolic AI = нейросети + символьная логика. Родственное: policy-as-code (правила как код, например OPA), rule engines, Datalog/Prolog.

## Почему не дать LLM решить целиком

| Задача | LLM | Код |
|---|---|---|
| «Scope 2 на стр. 11 = 2 777 т» из текста на нидерландском | ✅ | ❌ |
| 2 777 + 410 + перевод МВт·ч в кВт·ч | иногда ошибается | ✅ |
| «все 15 категорий покрыты?» | может не заметить 2 пропуска | ✅ разность множеств |
| дата отчёта ≤ 30.06.2025 | ✅ обычно | ✅ всегда |
| один и тот же ответ при повторе | нет | да |

## Как устроено

1. **Схема цели:** какие факты нужны и правило (`ratio >= 0.8`, `missing == ∅`). Может генерироваться LLM из текста цели, но потом это проверяемый артефакт
2. **Извлечение:** LLM заполняет схему, каждый факт + цитата + страница
3. **Правило:** код вычисляет `met / not met`
4. **Отказ:** нет факта, противоречие источников, неуспешно прочитанный файл → `needs review`, а не догадка

Плюс: видно *почему* решение такое — каждый шаг проверяется отдельно.

## Концепция шире

- **ФП:** functional core / imperative shell — чистое ядро решает, оболочка общается с грязным миром ([[pure-functions]])
- **Компиляторы:** парсер превращает текст в AST, дальше работают строгие правила
- **Бухгалтерия:** человек вносит первичку, итоги считает формула, а не человек

Общее везде: неточный этап «понять вход» отделить от точного этапа «вычислить вывод».
