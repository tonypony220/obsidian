```
  нужные куски (размечено вручную): {A, B, C}

  выдача top-5:   1. X   2. A   3. Y   4. B   5. Z
                         ✔          ✔
  recall@5    = 2/3   нашли 2 из 3 нужных
  precision@5 = 2/5   из 5 выданных нужных 2
  MRR         = 1/2   первый нужный на 2-м месте
```

**TL;DR:** Метрики поиска сравнивают выдачу с заранее размеченными правильными кусками. Recall — сколько нужного нашли, precision — сколько мусора в выдаче, MRR и nDCG — насколько высоко стоит нужное.

## Термины

| Метрика | Полностью | Вопрос, на который отвечает |
|---|---|---|
| recall@k | recall at k | какую долю всех нужных кусков нашли в первых k? |
| precision@k | precision at k | какая доля первых k — нужные? |
| MRR | Mean Reciprocal Rank | на каком месте первый нужный (в среднем по запросам)? |
| nDCG@k | normalized Discounted Cumulative Gain | насколько хорош порядок с учётом степени релевантности? |

## Формулы

$$
\text{recall@}k = \frac{|\text{нужные} \cap \text{top-}k|}{|\text{нужные}|} \qquad
\text{precision@}k = \frac{|\text{нужные} \cap \text{top-}k|}{k}
$$

$$
\text{MRR} = \frac{1}{|Q|}\sum_{i=1}^{|Q|} \frac{1}{\text{rank}_i}
$$

$\text{rank}_i$ — место первого нужного куска для запроса $i$. Первое место → 1, второе → 0.5, десятое → 0.1.

nDCG: каждому найденному куску даётся польза (например, 0/1/2), делённая на $\log_2(\text{место}+1)$ — чем ниже в списке, тем меньше засчитывается. Сумма делится на идеальный вариант → от 0 до 1.

## Какая метрика важна

- чат-бот «найди ответ»: MRR — достаточно одного хорошего куска наверху
- поиск для человека: nDCG, precision@k
- **проверка цели по всем условиям: recall** — каждый пропущенный кусок = неверное решение

## Evidence recall

Вариант recall из статей: доля *доказательств, необходимых для ответа*, которые попали к LLM. Отличие от обычного recall — считается по фактам, а не по кускам. Высокий recall@k может быть, а evidence recall низкий: нашли 5 кусков про Scope 3, но ни один не про категорию 4.

Для оценки нужна ручная разметка: какие куски правильные. Для Colvea — вручную разметить 2–3 цели. Готовые инструменты: Ragas (context recall, context precision).
