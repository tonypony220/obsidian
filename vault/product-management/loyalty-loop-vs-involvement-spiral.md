# Loyalty loop vs involvement spiral — два типа клиентского пути

back: [[customer-journey-map]]
next:
- [[loyalty-loop]]

---

```text
Loop:   задача → знакомый результат → доверие → повтор
Spiral: вход → любопытство → новый опыт → глубже → ... → выход
```

**TL;DR:** Для решения задачи ценность часто в предсказуемости; для досуга — в разнообразии самого опыта. Модели описывают дизайн сервиса и механик приложения, а не только контент.

## Как выбрать

| | Loyalty loop: гладкий путь | Involvement spiral: вовлекающий путь |
|---|---|---|
| Зачем приходит клиент | Получить результат | Получить впечатления от процесса |
| Основа возврата | Доверие и низкие усилия | Любопытство и развивающийся опыт |
| Повторный цикл | Знакомый и предсказуемый | Вариативный, с углублением вовлечения |
| Примеры категорий | Банки, страхование, транспорт | Игры, групповой фитнес, досуг |
| Покупка в модели авторов | Поощряется в ранних циклах | Поощряется в последующих циклах |

Классифицировать нужно **сценарий**, а не всё приложение: один сервис может соединять обе модели. Пример применения: поиск конкретной песни требует быстрого результата, музыкальное открытие допускает сюрпризы.

## Из чего складывается спираль

- Быстрый вход: первый опыт доступен без длинной подготовки.
- Любопытство: остаётся повод попробовать следующий цикл.
- Углубление: опыт меняется, растут участие и эмоциональная интенсивность.
- Вариативность: следующие циклы не исчерпываются повторением одного опыта.
- Монетизация: более глубокое участие может вести к разовым покупкам и апгрейдам.
- Постепенный выход: вовлечение не обязательно сохраняется навсегда.

Это описание динамики, а не обязательный набор функций. Стрик сам по себе не создаёт спираль; рост сложности и эмоциональные качели не нужны каждому продукту.

## Ошибка переноса

Сюрприз в досуге может быть ценностью; сюрприз в сроке перевода или составе заказа нарушает обещание сервиса. Даже внутри спирали оплата и базовое управление должны оставаться понятными.

Для смешанного сценария: рутинное выполнение сделать гладким, исследование — вариативным. Реализация гладкой части: [[loyalty-loop]].

Тезис «старый маркетинг перестал работать» из этой модели не следует: авторы предлагают два подхода для разных клиентских целей.
