Словарь терминов для описания структуры UI. **Chrome** — только одна из осей; важно не путать её с z-слоями и контентом.

## Структура / каркас

| Термин | Значение |
|---|---|
| **Chrome** | Весь обвес вокруг контента (статус-бары, тулбары, навбары, поповеры). Из "window chrome" — рамки окна браузера. |
| **Shell** | Оболочка приложения целиком. Паттерн **App Shell** в PWA — предзагруженный каркас, рендерится до контента для мгновенного first paint. |
| **Scaffold** | Базовая структурная обёртка страницы. Термин из Flutter/Material — компонент `Scaffold` с `appBar`, `body`, `bottomNavigationBar`, `drawer`. |
| **Frame** | Внешняя рамка. `iframe`, `window frame`, `frame rate` — разные значения, но всё про "обрамление". |
| **Layout** | Компоновка детей в контейнере — flex, grid, stack. |

## Контентная область

| Термин | Значение |
|---|---|
| **Viewport** | Видимая область экрана/окна. |
| **Canvas** | Рабочая поверхность (Figma, Photoshop, drawing apps). Бесконечная или ограниченная. |
| **Artboard** | Ограниченная область внутри canvas'а — один экран в дизайн-файле. |
| **Workspace** | Вся рабочая зона, включая панели инструментов. |
| **Stage** | В анимации/Flash/WebGL — область воспроизведения сцены. |

## Навигационные поверхности

| Термин | Значение |
|---|---|
| **Navbar / AppBar** | Верхняя полоса с заголовком и действиями. |
| **Tabbar** | Таб-бар, обычно нижний (iOS) или верхний. |
| **Rail** | Узкая вертикальная навигация — Material Navigation Rail, VSCode activity bar. |
| **Drawer** | Выдвижная боковая панель (hamburger menu). |
| **Dock** | Закреплённая панель с иконками — macOS Dock, iOS Dock. |
| **Sidebar** | Постоянная боковая панель. |

## Оверлеи (плавают поверх контента)

| Термин | Значение |
|---|---|
| **Modal / Dialog** | Блокирует взаимодействие с основным контентом. |
| **Popover** | Контекстный всплывающий блок, привязан к триггеру. |
| **Tooltip** | Мини-popover с подсказкой. |
| **Sheet** | Bottom sheet / side sheet (Material). Контекстно связан с экраном, в отличие от modal. |
| **Toast / Snackbar** | Временное уведомление с auto-dismiss. |
| **Banner** | Постоянное уведомление, встроенное в chrome. |
| **HUD** | Heads-Up Display — полупрозрачный оверлей поверх контента. Из игр, применимо к AR/картовым UI. |
| **Scrim / Backdrop** | Полупрозрачный слой, затемняющий фон при открытой модалке. |

## Системные зоны

| Термин | Значение |
|---|---|
| **Safe area** | Область, не перекрытая системными элементами — notch, home indicator, status bar. |
| **Inset** | Отступ от края, учитывающий системные элементы. |
| **Gutter** | Промежуток между колонками в grid. |

## Слои глубины

| Термин | Значение |
|---|---|
| **Z-layer / z-order** | Порядок элементов по глубине (CSS `z-index`). |
| **Elevation** | Material-термин — высота над поверхностью. Управляет тенью и z-order одновременно. |
| **Layer** | Слой композиции в общем смысле — Figma layers, CSS stacking context. |
| **Stacking context** | CSS-концепция: поддерево, внутри которого `z-index` изолирован от родителя. |

## Ортогональные оси — главный инсайт

Chrome, z-layer и контент — это **три независимые оси**, которые часто путают:

- **Chrome ось** = "какой набор элементов обвеса сейчас показан" → [[chrome-mode-fsm]]
- **Z-layer ось** = "на каком слое глубины они наслаиваются" → overlay stack, scrim, modal manager
- **Контентная ось** = "что в основной области" → карта, лента, canvas

Один компонент (например, "координатор оверлеев") не должен отвечать за все три одновременно. Классическая ловушка: сделать одну "доску объявлений", которая пытается быть и FSM для chrome, и менеджером z-слоёв, и контроллером контента. Такой компонент становится source of truth сразу для нескольких осей, и derivation-войны начинаются при первом же переходе между режимами.

Правильное разделение:
1. **ChromeMode reducer** — определяет, какие chrome-элементы рендерятся в данный режим.
2. **Overlay/layer manager** — управляет z-порядком модалок, поповеров, scrim'ов. Не знает про chrome.
3. **Content state** — отдельный слой (карта, список, canvas). Не знает ни про chrome, ни про overlay.
