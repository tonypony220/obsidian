# Random Forest

moc: [[ml-moc]]
next: [[logistic-regression]] [[svm]]

---

```
         ┌─── Дерево 1 ───► A ─┐
данные ──┼─── Дерево 2 ───► B ─┼──► голосование ──► A (2/3)
         └─── Дерево 3 ───► A ─┘
         (каждое дерево: случайный сабсет данных + фич)
```

Ансамбль из 100-500 деревьев решений. Каждое дерево — цепочка вопросов ("координата_156 > 0.3?"), обученная на случайном подмножестве данных и фич. Финальное решение — голосование большинства.

Много разных деревьев компенсируют ошибки друг друга — одно дерево легко переобучается, лес — устойчивее.

Риск: при 768 фичах и малом датасете (< 1000 примеров) склонен к переобучению — запоминает train вместо обобщения.
