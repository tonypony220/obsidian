# Lambda (регуляризация)

moc: [[ml-moc]]
next: [[learning-rate]] [[epochs]] [[cross-validation]]

---

```
  loss = error + λ × Σ(w²)
          │             │
     fit to data    penalty for
                    large weights

  λ→0: overfitting    λ→∞: underfitting
        ↑ complex            ↑ too simple
```

Штраф за большие веса. Добавляется к функции ошибки при обучении:

```
loss = ошибка_классификации + lambda × сумма(w²)
```

Без lambda модель может выставить `w42 = 500.0` чтобы идеально подогнаться под тренировочные данные — но на новых данных это сломается (overfitting). Lambda заставляет держать веса маленькими → модель ищет простое обобщённое решение.

Lambda — гиперпараметр, задаётся вручную до обучения. В sklearn это параметр `C = 1/lambda` (обратная величина). Подбирается через [[cross-validation|GridSearchCV]].

## Пример

3 координаты, модель ищет веса. `lambda = 0.1`.

**Без lambda** — модель нашла `w = [0, 0, 100]` (всё на одну координату):
```
loss = 0 ошибок + 0 (нет штрафа) = 0
```
На train идеально, на test — 60%.

**С lambda** — та же модель пробует `w = [0, 0, 100]`:
```
loss = 0 ошибок + 0.1 × (0² + 0² + 100²) = 0 + 1000 = 1000  ← дорого!
```

Ищет дальше, находит `w = [1.2, -0.8, 0.5]`:
```
loss = 2 ошибки + 0.1 × (1.44 + 0.64 + 0.25) = 2 + 0.233 = 2.233
```

2.233 < 1000 → модель выбирает второй вариант. Чуть больше ошибок на train, но маленькие веса → устойчивее на новых данных.

## Баланс

- Lambda слишком большая → underfitting (веса зажаты, модель слишком простая)
- Lambda слишком маленькая → overfitting (веса свободны, модель заучивает)
