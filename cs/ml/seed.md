# Seed (random state)

moc: [[ml-moc]]
next: [[cross-validation]] [[stratified-split]]

---

```
seed=42 ──► RNG ──► [0.37, 0.95, 0.73, ...]  ← запуск 1
seed=42 ──► RNG ──► [0.37, 0.95, 0.73, ...]  ← запуск 2  (идентично)

без seed ──► RNG ──► [0.12, 0.58, 0.44, ...]  ← запуск 1
без seed ──► RNG ──► [0.89, 0.03, 0.67, ...]  ← запуск 2  (разные)
```

Фиксирует генератор случайных чисел. `random_state=42` → каждый запуск даёт одинаковый сплит данных и одинаковый результат. Без seed — результаты скачут между запусками и сравнивать невозможно.

42 — традиция из "Автостопом по галактике", подойдёт любое число.
