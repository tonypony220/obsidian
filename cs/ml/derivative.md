# Производная

moc: [[ml-moc]]
next: [[optimizers-gd-vs-lbfgs]] [[learning-rate]]

---

```
  loss
   │       ╭──╮
   │      ╱    ╲
   │  ╱──╱      ·  tangent
   │ /  · ─────/── slope = dy/dx
   │/
   └──────────────── w
```

Отношение: насколько изменился выход при маленьком изменении входа.

```
производная = изменение_выхода / изменение_входа
```

## Пример

`loss(w)`. Стоим в `w = 3`, loss = 10. Сдвигаем `w = 3.001`, loss = 9.998.

```
производная = (9.998 − 10) / (3.001 − 3) = −0.002 / 0.001 = −2
```

Производная = −2 → при сдвиге w на +1, loss изменится на −2. На графике это наклон кривой в данной точке.

## Вторая производная

То же действие, но применённое к первой производной — как быстро меняется наклон.

```
в w=1:     производная = −2
в w=1.001: производная = −1.99

вторая производная = (−1.99 − (−2)) / 0.001 = +10
```

Наклон быстро выравнивается → кривая загибается → дно близко.

## Аналогия с физикой

Производная — это обобщение формулы скорости. Та же математика, другие переменные:

```
физика                        ML
──────────────────────────────────────────
положение(t)                  loss(w)
скорость = d(положение)/dt    градиент = d(loss)/dw
ускорение = d(скорость)/dt    кривизна = d(градиент)/dw
```
