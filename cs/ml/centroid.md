# Центроид

moc: [[ml-moc]]
next: [[differential-score]] [[logistic-regression]]

---

```
  v1=(1,3) v2=(3,4) v3=(2,1)

  ·  v2              centroid = (
  ·        ★ ←─────    (1+3+2)/3,
  v1            ·       (3+4+1)/3
  ·     v3      ·     ) = (2, 2.67)
```

"Средняя точка" группы векторов. Берём все эмбеддинги класса (например, relevant сообщений), складываем поэлементно и делим на количество. Получаем один вектор — "типичный представитель" класса.

Новое сообщение сравниваем с центроидами обоих классов — к какому ближе, туда и относим.

Простейший метод классификации. Ограничение — усредняет все измерения одинаково, не учитывая какие координаты важны для разделения.
