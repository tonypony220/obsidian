```
СТОРОНА А ───── контракт (спецификация) ───── СТОРОНА Б
железо /         «на действие X — ответ Y»     софт /
загрузчик        фиксирует НАБЛЮДАЕМОЕ         ядро
                 поведение навсегда;
                 реализация внутри — любая
```

**TL;DR:** контракт — зафиксированная в опубликованной спецификации граница: раскладки байтов, адреса, последовательности действий, состояние на момент передачи управления. Обещано только наблюдаемое поведение; как оно устроено внутри — не оговорено и может меняться. Ядро — программа, у которой под ногами НЕТ ничего, кроме контрактов.

## Контракты, уже встреченные в KFS

| Контракт | Стороны | Суть обещания |
|---|---|---|
| [[multiboot]] | загрузчик ↔ ядро | магия 0x1BADB002 в первых 8 КБ → управление в известном состоянии (EAX=0x2BADB002, protected mode, ESP не определён) |
| [[elf-format]] program headers | линкер ↔ загрузчик | «эти байты положи по этому адресу, вход там-то» |
| [[vga-text-mode]] | софт ↔ видеокарта | 0xB8000, клетка = 2 байта (символ+атрибут), сетка 80×25 |
| карта первого МБ ([[linker-script]]) | платформа ↔ весь софт | замороженные диапазоны: 640К RAM, окно видео, ROM'ы, RAM с 1M |
| PCI config space ([[buses-and-controllers]]) | прошивка/ОС ↔ любая карта | координаты bus:device:function → 256 байт стандартной раскладки (vendor ID @0x00, class, BAR'ы @0x10+), sizing все-единицами |
| System V ABI ([[stack-is-a-convention]]) | компилятор ↔ компилятор | соглашение вызова, выравнивание стека 16 |

## Свойство: физика умирает — контракт живёт

PCI: общая параллельная шина с IDSEL-проводами (1992) → PCIe: личные serial-линки и пакеты. Раскладка конфиг-пространства и алгоритм переклички не изменились ни на байт. VGA: от ISA-карт до современных GPU — окно 0xB8000 отвечает. Софт, написанный по контракту, переживает любую смену железа под ним.

## Следствия

- **Виртуализация возможна в принципе**: контракт фиксирует только наблюдаемое поведение → QEMU реализует его программно, гость не может отличить ([[buses-and-controllers]])
- **Совместимость сквозь десятилетия**: BIOS, написанный до рождения твоего диска, работает с ним — потому что говорит не с диском, а со стандартным классом контроллера
- **Ядро стоит только на контрактах**: libc нет, ОС нет ([[freestanding-environment]]) — опереться можно лишь на контракты железа и загрузчика. Этап 1 = исполнение трёх контрактов (multiboot, ELF, ABI); этап 2 — четвёртого (VGA)
