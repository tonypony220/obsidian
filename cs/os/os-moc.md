# OS / Kernel Development

Точка входа в заметки по разработке ОС и ядра. Контекст: проект KFS (École 42) — ядро с нуля (`~/ecole42-projects/kfs`, спека `docs/specs/kfs1-spec.md`).

## Загрузка

- [[boot-process]] — цепочка от кнопки питания до kmain(): BIOS → GRUB → ядро
- [[multiboot]] — контракт «пометь себя заголовком — получишь управление в известном состоянии»
- [[protected-mode]] — режимы x86: почему ядро стартует сразу в 32-битном protected mode

## Окружение ядра

- [[freestanding-environment]] — код без libc и ОС под ногами; что отключает каждый флаг компилятора
- [[interface-contracts]] — на что опирается ядро, когда нет ОС: спецификации наблюдаемого поведения; физика меняется — контракт живёт
- [[elf-format]] — формат исполняемого файла: «накладная» для загрузчика — что куда в память и где вход
- [[code-and-data-are-bytes]] — asm-файл = рецепт байтов; «код» и «данные» — роли, назначаемые читателем
- [[stack-is-a-convention]] — стек = esp + кусок обычной RAM; push/pop слепые; кто делает стек программе
- [[cross-compilation]] — host ≠ target: почему clang с macOS не соберёт ядро
- [[linker-script]] — ручное управление раскладкой бинарника в памяти

## Инструменты

- [[binary-inspection-cheatsheet]] — nm/objdump/readelf: глаза для бинарников + ручная сборка

## Железо

- [[bus-cycle]] — как физически исполняется один mov: три пучка проводов, декодер, chip-select
- [[memory-mapped-io]] — устройства, видимые как память (и как порты in/out)
- [[buses-and-controllers]] — CPU не видит устройств, только регистры контроллеров; перекличка шин (enumeration)
- [[vga-text-mode]] — текстовый экран: массив ячеек по адресу 0xB8000
