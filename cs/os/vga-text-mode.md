# VGA text mode

back: [[memory-mapped-io]]
next:

---

```
0xB8000: сетка 80×25, ячейка = 2 байта
┌─────────────┬──────────────────┐
│ байт 0      │ байт 1 (attr)    │
│ ASCII/CP437 │ bg(4 б.) fg(4 б.)│
└─────────────┴──────────────────┘
адрес ячейки: vga[row * 80 + col]
значение:     attr << 8 | ch
```

**TL;DR:** текстовый экран — массив 80×25 двухбайтовых ячеек, отображённый на физический адрес 0xB8000; записал ячейку — символ мгновенно на экране, никаких «драйверов».

## Формат ячейки

- Байт 0 — символ в кодировке CP437 (ASCII + рамки, стрелки, тени).
- Байт 1 — атрибут: младшие 4 бита — цвет текста, старшие 4 — фон (16 цветов; бит 7 исторически «blink»).
- В C: `uint16_t cell = (uint16_t)ch | (uint16_t)attr << 8` (x86 little-endian).
- «42» светло-серым по чёрному: attr = 0x07.

## Почему volatile

Компилятор не знает, что запись по 0xB8000 — сайд-эффект (пиксели на экране). Без `volatile` он вправе выкинуть «мёртвые» записи или переупорядочить их. Подробнее — [[memory-mapped-io]].

## Что строится поверх (терминал)

- Состояние: текущие `row`/`col` + текущий цвет.
- `putchar`: записать ячейку, продвинуть курсор, обработать `\n`.
- Scroll: сдвиг строк 1–24 на место 0–23, очистить последнюю. Семантика memmove (области пересекаются), но по volatile-ячейкам — **явный цикл**: передать volatile-указатель в memmove = молча снять volatile-контракт кастом.
- Аппаратный курсор — секция ниже.

## Аппаратный курсор

Мигающий прямоугольник рисует **сама карта** — каждый кадр, по своему регистру позиции. Он ≠ `row`/`col` терминала: два независимых учёта (SeaBIOS оставляет регистр под своим логом — курсор «висит» посреди экрана, пока ядро его не перепрограммирует). Регистры — за портами 0x3D4/0x3D5 (PMIO, [[memory-mapped-io]]), протокол **index/data**: в 0x3D4 НОМЕР внутреннего регистра (0x0E/0x0F = старший/младший байт позиции), в 0x3D5 — байт данных. Позиция = `row*80+col` (0–1999), 16 бит → два захода. Синк — после каждого `putchar`.

Строки для этого экрана — **только ASCII**: байт 0 ячейки трактуется как CP437, а исходники в UTF-8 кодируют всё вне ASCII несколькими байтами → `—` (e2 80 94) отрисуется тремя глифами-мусором `Γ Ç ö`.
