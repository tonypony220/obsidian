# tun/tap

next: [[veth-pair]]

---

```
 Userspace (VPN-клиент)
        │
        │ read()/write()
        ▼
 ┌─────────────┐
 │  /dev/tunX   │  ← виртуальная сетевая карта
 └──────┬──────┘
        │
        ▼
   Ядро Linux
  (сетевой стек)
```

Виртуальная сетевая карта. Позволяет userspace-программе напрямую читать и писать сетевые пакеты, минуя физическое железо.

## tun vs tap

- **tun** — работает на L3 (IP-пакеты). Используется для IP-туннелей
- **tap** — работает на L2 (Ethernet-кадры). Используется для мостов и VM

## Где используется

- **VPN** — OpenVPN, WireGuard читают пакеты из tun-интерфейса, шифруют и отправляют через реальную сеть
- **VM** — QEMU/KVM использует tap-интерфейсы для подключения виртуальных машин к сети хоста
